# SmartBite - Project Statement

## Problem Statement

Students and other users often have different preferences when choosing fast-food items, such as calorie limits, protein requirements, budget, brand, and food category. Comparing available options manually can be inconvenient.

SmartBite provides a simple command-line system that helps users find suitable fast-food options based on these requirements and also supports comparison, cart management, and simulated checkout.

## Scope

The project focuses on a Python-based command-line application. It uses a small locally stored food dataset and provides recommendation, filtering, comparison, cart, and simulated ordering functionality.

The current version does not use live restaurant data, real payments, a database, or a graphical user interface.

## Target Users

- Students
- Fitness-conscious users
- Users looking for food options within a budget
- Users who want to compare basic food information before ordering

## High-Level Features

- User registration and login
- Guest mode
- Food recommendations based on calories, protein, and budget
- Brand and category filtering
- Recommendation modes:
  - Cheat Meal
  - High Protein
  - Low Calorie
  - Best Value
- Recommendation ranking
- Closest alternatives when no exact match is available
- Food comparison
- Shopping cart with quantity management
- Cart total calculation
- Simulated payment selection
- Order confirmation

## Technologies Used

- Python
- Python lists and dictionaries
- Functions
- Conditional statements
- Loops
- Exception handling
- Modular programming

## Project Limitation

The food information used by SmartBite is stored locally and the calorie, protein, and price values are illustrative/sample values for academic demonstration. The application does not provide real-time nutritional, restaurant, or payment information.
